# natehall329.github.io

Source for my academic website: **[natehall329.github.io](https://natehall329.github.io)**

I'm Nate Hall, a PhD candidate in Psychology and Neuroscience at UNC Chapel Hill. I use computational psychiatry methods (reinforcement learning models, Bayesian multilevel modeling, eye-tracking) to study how affect shapes learning and decision-making in personality pathology.

The site has my research, publications, CV, and (soon) tutorials.

Built with [Hugo](https://gohugo.io) and the [Hugo Blox](https://hugoblox.com) Academic CV template, deployed to GitHub Pages via GitHub Actions.
